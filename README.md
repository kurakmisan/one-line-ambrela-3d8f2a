One line: the AI finishes your sentence, your paragraph, and then your career — in that order. An escalation joke with a double meaning on "finished": it completes your writing, then ends your job.

`main.py` writes that single line (72 characters, UTF-8, no trailing newline) to `/output/entry.txt`. Python standard library only, no network, the same bytes on every run. It refuses to write anything that is not one line of 1 to 140 characters.

## Run it

```sh
python3 main.py                              # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py       # writes out/entry.txt
```
